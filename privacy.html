개인정보처리방침

1. 적용 범위와 운영자

이 방침은 개인 운영자가 제공하는 OpenClaw Gmail Assistant의 Google 계정 연동 및 관련 작업 처리에 적용됩니다. 개인정보 관련 문의와 삭제 요청 연락처는 jongho.jung@yonsei.ac.kr입니다.

2. 접근하는 정보

계정 연결 및 식별을 위한 이메일 주소·기본 계정 식별정보, OAuth 권한 및 토큰을 처리합니다. 사용자 요청에 따라 이메일 본문·헤더·첨부파일, Drive 파일의 메타데이터·내용, Sheets 문서의 데이터에 접근할 수 있습니다. 실제 접근 대상은 사용자가 부여한 Google 권한과 요청한 작업에 따라 달라집니다.

3. 이용 목적

계정 연결 유지, 사용자가 요청한 이메일 검색·요약, 문서·파일 조회 및 관리, 스프레드시트 작업, 작업 결과 제공과 필요한 문제 해결에 정보를 사용합니다. Google 사용자 데이터를 판매하거나 광고 타기팅에 사용하지 않습니다.

4. AI 처리 및 외부 서비스

요청 수행에 필요한 Google 데이터가 OpenClaw에 설정된 AI 제공업체(예: OpenAI)에 입력으로 전달될 수 있습니다. 결과 및 작업에 필요한 내용은 사용자가 작업을 요청한 메시징 서비스(예: Discord)를 통해 전달될 수 있습니다. AI 처리, 메시징 및 호스팅에는 각 제공업체의 처리·보관 정책도 적용됩니다. Google 데이터와 연결된 결과는 민감한 정보가 될 수 있으므로 사용자는 적절한 대화 대상과 공간에서 작업을 요청해야 합니다.

5. Google API 데이터 이용 제한

Google API에서 받은 정보의 이용 및 다른 앱으로의 이전은 Limited Use 요건을 포함한 Google API Services User Data Policy를 따릅니다. Google 사용자 데이터를 범용 AI 또는 머신러닝 모델의 개발·개선·학습 목적으로 사용하지 않습니다. 사용자 요청을 수행하기 위한 모델 추론은 범용 모델 학습과 구분됩니다.

6. 저장과 접근 관리

OAuth 인증정보는 이 공개 웹사이트나 공개 GitHub 저장소가 아니라 운영 서버의 인증정보 저장소에서 관리합니다. 작업 내용과 결과는 서버의 대화 기록·작업 파일 또는 사용자가 선택한 서비스에 남을 수 있습니다. 접근 권한을 관리하고 작업에 불필요한 공개를 피합니다. 이 안내 사이트에는 앱이 추가한 광고·분석 스크립트가 없지만, 호스팅 제공업체 GitHub는 보안 등을 위해 방문자의 IP 주소를 기록할 수 있습니다.

7. 보관과 삭제

인증정보는 연동 유지에 필요한 동안 보관하며, 불필요해지거나 삭제 요청이 있으면 해당 서버에서 삭제합니다. 대화 기록·작업 파일·백업에는 별도의 보관 설정이 적용될 수 있으며, 모든 기록에 대한 일정한 자동 삭제 기간을 보장하지 않습니다. 삭제 요청을 받으면 대상과 보관 위치를 확인하고 운영자가 관리할 수 있는 범위에서 처리하며, 백업이나 외부 서비스로 인한 제한이 있으면 안내합니다.

8. 권한 철회와 요청

사용자는 Google 계정의 타사 앱 및 서비스 연결 설정에서 권한을 철회할 수 있습니다. 철회하면 이 앱의 새로운 Google 접근이 제한되지만, 기존에 보관된 기록이나 이미 전달된 메시지가 자동으로 삭제되지는 않습니다. 해당 기록의 삭제·정정 요청은 jongho.jung@yonsei.ac.kr로 보내주세요.

9. 방침 변경

기능이나 데이터 처리 방식이 변경되면 이 페이지를 갱신하고, 필요한 경우 사용자에게 안내하거나 추가 동의를 받습니다. 시행일: 2026년 10월 27일.

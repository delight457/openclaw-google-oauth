앱 소개

OpenClaw Gmail Assistant는 운영자와 운영자가 허용한 소수 사용자가 자신의 Google 계정을 OpenClaw 작업 도우미에 연결하는 개인용 도구입니다. Google의 공식 제품이나 서비스가 아닙니다.

제공 기능

사용자가 요청한 Gmail 검색·읽기·요약, Google Drive 파일 조회·관리, Google Sheets 데이터 조회·편집을 돕습니다. Google 계정 연결에는 gog CLI의 사용자 OAuth 인증을 사용합니다. 각 작업은 해당 계정이 허용한 권한과 운영 지침 범위에서 수행합니다.

Google 권한과 실제 사용

현재 구성은 Gmail 읽기 및 작성·전송 관련 범위, Drive 전체 접근 범위, Sheets 읽기·쓰기 범위를 포함합니다. 권한 부여 자체가 모든 작업의 실행 승인을 뜻하지는 않습니다. 현재 Gmail은 읽기 중심으로 운영하며, 이 앱은 사용자의 별도 지시 없이 메일을 자동 발송하지 않습니다. 추가 쓰기 작업은 사용자 요청과 적용되는 승인 절차를 따릅니다.

이 웹사이트의 역할

이 사이트는 앱의 기능과 데이터 처리 방침을 공개하는 안내 페이지입니다. 이 사이트에서 Google 로그인, 인증정보 입력 또는 메일·파일 업로드를 받지 않습니다. 실제 Google 연결 및 작업은 별도의 운영 환경에서 이루어집니다.
